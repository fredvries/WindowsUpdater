I know, you can easily force Windows Update via Settings > Windows Update > Check for Updates.

But that can be simplified by a simple batch file. Which I've created. Enter WindowsUpdater.

Instructions:
- Download the batchfile to your Desktop
- Run as an Administrator (Right-click > 'Run as admin')
